How it was measured

  • Shallow clone (depth 1) of the default branch. File names and package.json text were scanned; node_modules, dist, build and similar folders were excluded.
  • Token files: files with "token" in the path. Format: DTCG if "$value" is present, Style Dictionary if package.json mentions it, otherwise CSS custom properties.
  • Components (strict): folders under a "components" directory that contain a source file named after the folder or an index file. Component dirs (proxy) counts every folder named "components" and its children and is not a valid component count: across 214 repositories its median is 26.5 against 2.5 for the strict rule.
  • A11y in source: source or test files that import or reference axe, jest-axe, pa11y, eslint-plugin-jsx-a11y or the Storybook a11y addon. "A11y deps" lists the matching package names.
  • Stories counts .stories files including .mdx. A self-audit of 20 random repositories agreed on token, story and Code Connect counts in 19 of 20; the one difference came from excluding .mdx stories in the audit, not from a measurement error.
  • Release tags from git ls-remote; semver tags match x.y.z.

Limits

  • Seven repositories are private or not public (Astro, Bolt, Co-op, Jobber, FT Origami, Audi, Scania) and show "not_checked".
  • Monorepos may be undercounted: the scan cap is 60,000 files per repository.
  • Presence of a tool does not show that it is used for every component.
  • Coding was done by the author. Independent coders have not yet checked a sample.
  • Single collection date; repositories change.
